Neural Circuit Visualizer

Neural Circuit Visualizer (NCV) – User Guide

Version 1.0, April 2025

Overview

The Neural Circuit Visualizer (NCV) is a web-based application that enables users to interactively upload, visualize, and analyze large-scale hippocampal neuron circuits. The platform supports a streamlined workflow from network and activity file upload to dynamic 3D circuit visualization and spike playback.

  1. Data Upload : Upload neural network and spike activity data in supported formats (CSV or HDF5).
  2. 3D Visualization : Explore neuron distributions and network structure with anatomical orientation.
  3. Playback and Analysis : Animate spike activity over time and examine firing statistics across simulation chunks.

Uploading Data

Supported Formats

  • CSV files : Separate .csv for Network and Activity.
  • HDF5 files : Single .hdf5 containing both datasets.
📝 Format:
  • Network file: Gid, X, Y, Z
  • Activity file: Gid, Time

Upload Process

  1. Click UPLOAD DATA on the sidebar.
  2. Select either .csv or .hdf5 upload button.
  3. Wait for upload and chunking to complete (progress bar displayed).
  4. After processing, your 3D circuit visualization appears.

Visualizing the Circuit

A 3D scatter plot of neurons is generated, color-coded by type:

  • Excitatory Neurons (Blue)
  • Inhibitory Neurons (Red)
  • Firing Excitatory Neurons (Yellow)
  • Firing Inhibitory Neurons (White)

Axes:

  • A (Anterior) - P (Posterior)
  • D (Dorsal) - V (Ventral)
  • M (Medial) - L (Lateral)
🧭 Axes orientation is computed automatically via Principal Component Analysis (PCA) .

Neuron Count Summary Panel

This panel presents a real-time summary of the neuron population currently loaded into the 3D circuit visualizer. The values are automatically computed upon network file upload and include the following:

  • Total Neurons : The complete number of neurons parsed from the network file. This includes both excitatory and inhibitory types, regardless of whether they fire during simulation.
  • Excitatory Neurons : Neurons that depolarize post-synaptic targets upon firing. In hippocampal circuits, these are typically glutamatergic principal cells such as pyramidal neurons or granule cells.
  • Inhibitory Neurons : Neurons that hyperpolarize post-synaptic targets to suppress excitation. These are typically GABAergic interneurons.

These counts help users quickly assess the balance between excitation and inhibition in the visualized network — a key factor in analyzing neural dynamics, signal propagation, and circuit stability.

Simulation Controls

Use the toolbar at the top:

  • Chunk Selector : Choose time windows
  • Start , Pause , Restart buttons to control playback

Firing Activity

After upload:

  • Chunk-based spike analysis is performed.
  • Histogram of spike counts over time is displayed.
  • Mean Firing Rate (MFR) is computed per chunk.
  • Firing Excitatory Neurons (Yellow)
  • Firing Inhibitory Neurons (White)

Additional Features

Interactive Time Slider

The Interactive Time Slider allows users to control simulation playback over time:

  • Current Time Display : Shows the current simulation time t and total duration (in milliseconds).
  • Start / End Time Inputs : Users can define a custom simulation window using the “Start” and “End” fields to restrict playback to a specific range.
  • Slider Handle : Drag the blue circle along the timeline to scrub through the simulation manually.

This panel enables precise control over which portion of the spike activity timeline is visualized.

Visualization Panel

  • Background Color : Customize the background of the 3D scene using a color picker. You can input a hex code or use the interactive selector to improve contrast.
  • Camera Controls : Adjust the camera position in 3D space using x , y , and z sliders. Each slider is accompanied by a numeric input for precision control.
  • Neuron Size : Control the default size of all neurons using a range slider and manual input field.
  • Firing Neuron Size : Set the enlarged size of neurons during spike animation separately for better visual emphasis.

Playback Configuration

  • Playback Speed : Modify how fast spikes are animated by adjusting the time scale.
  • Step Duration : Define the real-time delay (in milliseconds) between animation frames. Lower values result in faster playback, while higher values create slower, more controlled animations.

Visualizing Demo Circuits

If you do not have your own network and activity files yet, you can explore the platform by loading one of the provided Demo Circuits . This allows immediate 3D visualization without uploading your own data.

Human Circuit Demo

Under the \"Human Circuit\" tab, you can:

  • Click the Load Circuit button to visualize the CA1 hippocampal network.
  • Use the Select Activity dropdown to load predefined spiking data for playback.
  • Animate spikes and explore network dynamics through the simulation controls.

Mouse Circuit Demo

The Mice Circuit provides an advanced demo mode, allowing users to selectively visualize specific hippocampal regions, layers, and neuron types before loading the network. The neuron type definitions and census data are curated based on the mice hippocampal neuron classifications available from Hippocampome.org . This ensures that the anatomical structure and cell-type representation in the demo circuits reflect up-to-date experimental knowledge from peer-reviewed literature.

The distribution of glutamatergic (excitatory, marked with an X ) and GABAergic (inhibitory) neurons of distinct types across each subregion and layer of the hippocampal formation is incorporated, based on Hippocampome.org data. This organization allows users to accurately explore the spatial arrangement of excitatory and inhibitory populations within different anatomical subdivisions such as the Dentate Gyrus (DG), CA3, CA2, CA1, Subiculum, and Entorhinal Cortex (EC).

The workflow is:

  1. Expand the Mice Circuit tab.
  2. Click Load Circuit before making selections to visualize only the selected neurons.
  3. (Optional) Build specific connections (e.g., CA3-PC to CA1-PC) before visualization if needed.
  4. Select the desired network part under Hippocampal Formation :
    • Toggle specific anatomical regions (e.g., DG, CA3, CA2, CA1, Subiculum, EC).
    • Further refine your selection by choosing specific hippocampal layers (e.g., SLM, SR, SP, SO).
    • Enable/disable specific Neuron Types within each region (e.g., Granule cells, Basket cells, Mossy fibers).
  5. Select a corresponding Activity dataset if available to animate firing patterns.
    Example: Activity visualization in CA3 based on simulations from Kopsick et al., bioRxiv, 2024 .
